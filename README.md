# CROSS SUPER website demo

Static Cross Super website with 14 pages and the existing product interactions.

## Latest update

- Homepage and Store Locator share the original live Thailand map and its 255 store records.
- Selecting a province on the homepage lists every matching store in a scrollable panel.
- Selecting a store updates its details and the active map marker.
- Store detail and Google Maps links retain the real store information.
- Existing product interactions, store data, and media assets are retained.

## Run

Serve this directory with an HTTP server and open `index.html`.

- Homepage: `#home`
- Store Locator: `#stores`
- News: `#news`

The news page uses the official Facebook Page Plugin; timeline availability depends on Facebook and the browser. No generated posts or reviews are used.

Static HTML/CSS/JavaScript; no build step or runtime secrets. `.nojekyll` keeps the repository ready for GitHub Pages.
